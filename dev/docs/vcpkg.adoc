[cmake] The package python3 is compatible with built-in CMake targets:
[cmake] 
[cmake]     find_package(Python3 COMPONENTS Development REQUIRED)
[cmake]     target_link_libraries(main PRIVATE Python3::Python)
[cmake] 
[cmake] The package python3 provides a python interpreter that supports virtual environments:
[cmake] 
[cmake]     $ tools/python3/python3.12 -m venv /path/to/venv
[cmake]     $ export VIRTUAL_ENV=/path/to/venv
[cmake]     $ export PATH=/path/to/venv/bin:$PATH
[cmake]     $ export -n PYTHONHOME
[cmake]     $ unset PYTHONHOME
[cmake] 
[cmake]     See https://docs.python.org/3/library/venv.html for more details.
[cmake] 
[cmake] The package boost-python is compatible with built-in CMake targets of FindBoost.cmake:
[cmake] 
[cmake]     find_package(Boost REQUIRED COMPONENTS python)
[cmake]     target_link_libraries(main PRIVATE Boost::python)
----
